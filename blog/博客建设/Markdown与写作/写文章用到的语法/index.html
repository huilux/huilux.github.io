代码块

代码块格式如下

int main() {
    return 0;
}

对应的 MarkDown 写法

```c
int main() {
    return 0;
}
```

如果想要添加行号：{linenos=table}

有两个参数

  • inline：代码行号内联在代码块里，鼠标框选代码时会选中行号

  • table：鼠标框选代码时不会选中行号，方便复制粘贴 table 目前有个小瑕疵就是行号和代码对不齐，需要在文章的 CSS 中设置一下 line-height：

添加行号和设置起始行：{linenos=table, linenostart=21}

行高亮：{linenos=table, hl_lines=[2 “5-6”]}
